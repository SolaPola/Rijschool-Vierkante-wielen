# CRUD Appointment Management System

This project is a **CRUD-based web application** built with **Laravel**.  
It provides a simple and intuitive interface for managing **appointments, packets, and related records**.  
The system includes **authentication with middleware protection**, database migrations, and MySQL integration.

---

## 🚀 Features

- 🏠 **Home Screen** – Clean and user-friendly landing page.
- 🔐 **Authentication** – Login system protected by middleware.
- 🗂️ **CRUD Operations** – Create, Read, Update, and Delete:
  - Appointments
  - Packets
  - (Extendable for other entities)
- 💾 **Database Integration** – Powered by **MySQL** with migration files.
- ⚡ **Laravel Framework** – Built on Laravel for scalability and maintainability.

---

## 🛠️ Tech Stack

- **Backend:** Laravel (PHP Framework)
- **Database:** MySQL
- **Authentication:** Laravel Middleware
- **Frontend:** Blade Templates (with Bootstrap/Tailwind, if used)
- **Migrations:** Laravel’s built-in migration system
